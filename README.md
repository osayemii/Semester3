# Semester3

**School:** Aptech

**Bio:** Aptech Semester 3 programming coursework covering Dart, Flutter, and sample Dart projects.

**Description:** Semester 3 coursework organized by project folder.

## Root folders

| Folder | Stack | What it contains |
| --- | --- | --- |
| `flutter/` | Dart, Flutter | Flutter/Dart apps and class projects. |
| `mypackage/` | Dart | Dart package coursework. |
| `sample_dart_project/` | Dart | Sample Dart CLI project. |

Only root folders are listed. Generated caches, package folders, editor settings, and other non-personal folders are omitted.

## Running the code

There is no single entry point for the whole repo; run individual projects from their folders. Check each folder for its own README, `package.json`, `pubspec.yaml`, `pom.xml`, or build files.
